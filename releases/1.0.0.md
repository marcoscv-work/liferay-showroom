First published release of the Liferay Sites design system as plain Liferay assets: 27 component fragments and 13 page blocks converted from the React design system, the LSDS Home page template composing the blocks, and the LSDS Light and LSDS Dark style books carrying the design tokens. The images and videos the page blocks use ship as resources of the fragment set, so the set imports without reaching the design system host.
